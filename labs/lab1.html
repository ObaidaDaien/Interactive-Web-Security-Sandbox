Client-Side URL Redirect

Follow a phishing redirect from the attacker-created link to the victim's trusted portal, then run the identical path after the fix.

01 What it is

Understand the weakness

Open Redirect happens when browser-side code accepts a user-controlled URL as a navigation destination without checking that it is trusted. An attacker can make a trusted-looking portal link send a victim to a phishing page. This lab safely previews the destination instead of navigating to it.

OWASP: Client-side TestingCWE-601
02 The line

Where the unsafe behavior begins

The dangerous sink is the navigation call: it uses attacker-controlled data before an origin or path check.

redirect-vulnerable.jsVULNERABLE CODE
01function getDestination(value) {02  try {03    const target = new URL(value, location.origin);04    return target;05  } catch {06    return null;07  }08}09const userInput = new URLSearchParams(location.search).get("next");10const destination = getDestination(userInput);11if (destination) location.assign(destination.href);

Why it is unsafe: Parsing a URL does not establish trust. This line sends the victim to any parsed destination.

04 Why it matters

What can go wrong?

A trusted-looking link can make credential theft more convincing because the victim starts on a familiar domain. The safe local preview represents the phishing destination without contacting it.

05 The fix

Allow only application-controlled routes

Require the portal origin and an approved path before navigation. Mapping known route names to internal destinations is even safer.

redirect-fixed.jsFIXED CODE
01const allowedPaths = ["/home", "/profile"];02function getSafePath(value) {03  try {04    const target = new URL(value, location.origin);05    if (target.origin !== location.origin) return "/home";06    if (!allowedPaths.includes(target.pathname)) return "/home";07    return target.pathname;08  } catch { return "/home"; }09}10const userInput = new URLSearchParams(location.search).get("next");11location.assign(getSafePath(userInput));
