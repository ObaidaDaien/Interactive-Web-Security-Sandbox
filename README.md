# Interactive Web Security Sandbox

## Project Description
This project is a browser-based learning space with three interactive web security labs. Each lab shows a safe attack story: the attacker prepares a payload, a victim or target application receives it, and the result changes between vulnerable and fixed modes.

## Security Labs
- Client-Side URL Redirect
- postMessage Origin Validation
- Regular Expression Denial of Service (ReDoS)
