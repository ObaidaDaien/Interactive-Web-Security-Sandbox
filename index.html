BEFORE YOU START

How the sandbox works

Every lab follows a safe attack story: an attacker prepares input, a victim or target application receives it, and the result explains what changed after the fix.

01 ⌕

Choose a lab

Open one of the three security topics and read what the weakness means.

02 { }

Choose a version

Switch between Vulnerable and Fixed, then run the same attacker payload again.

03 ↗

Load a payload

Select a test input. It is placed into the relevant field in the lab application.

04 ✓

Run and compare

Run the test, observe the application, then use the same input against the fixed version.

i

Good to know: These are isolated teaching demonstrations. Reserved example domains and synthetic data are used; no real website or personal account is targeted.
